MailDownloader

תוכנת Windows שמורידה וממיינת חומרי צילום שמגיעים במייל

מה התוכנה עושה

MailDownloader מיועדת למשרד צילום. היא סורקת את תיבת ה-Gmail של המשרד ומאתרת מיילים שצלמי המשרד שלחו עם קבצים או עם קישורי הורדה מ-JumboMail ומ-MyAirBridge. התוכנה מורידה את החומרים למחשב המשרד וממיינת אותם לתיקיות לפי תאריך, אירוע וצלם.

התוכנה רצה רק על מחשב המשרד. אין לה שרת חיצוני, והחומרים נשמרים רק במחשב הזה.

מדיניות הפרטיות

About MailDownloader

MailDownloader is a Windows desktop application for a photography office. It scans the office's Gmail inbox for messages from the office's photographers that contain attachments or JumboMail / MyAirBridge download links. It downloads the files to the office computer and sorts them into folders by date, event and photographer.

The application runs only on the office computer. It has no external server, and all files stay on that computer.
